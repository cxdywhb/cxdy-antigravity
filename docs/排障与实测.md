# Antigravity 启动与模型加载排障

归档日期为 2026 年 11 月 22 日。记录来自一台 Apple Silicon Mac 上的官方 Antigravity 2.34.0。

## 故障与根因

从 macOS 应用列表直接打开 Antigravity 后，模型下拉菜单显示 `No models available`。刷新时报 `Error Loading Models`，`daily-cloudcode-pa.googleapis.com` 的 `loadCodeAssist` 请求连接公网 443 端口超时。

故障发生时，Clash Verge 的系统代理已启用，TUN 已关闭。Antigravity 的 `language_server` 进程没有代理环境变量，也没有连接 Clash 的本地代理端口。通过带代理参数的脚本启动后，后端能够加载模型。

## 修复

Antigravity 2.34.0 启动后端前会读取登录 Shell 的环境。App 在读取时主动设置 `ANTIGRAVITY_RESOLVING_ENVIRONMENT=1`，然后把读取到的变量传给 `language_server`。

在用户的 `.zshenv` 中增加一个带条件的配置段。只有该标记为 `1` 时才设置 HTTP 和 HTTPS 代理为 `http://127.0.0.1:7897`，并让 `localhost`、`127.0.0.1` 和 `::1` 绕过代理。日常从官方图标启动即可。Clash 需要保持运行，TUN 可以关闭。

验证时先清空启动命令继承的代理变量，再打开官方 App。主进程没有代理变量或调试参数，后端继承了代理变量，并建立了 14 条到 Clash 的连接。强制刷新模型列表返回 38 个条目。Google 原始签名通过校验。该测试覆盖模型列表加载，未发送模型对话。

## 复发时如何定位

1. 确认 Clash 正在运行，混合端口仍为 `7897`。
2. 用 `⌘Q` 退出 Antigravity，再从官方图标重新打开。代理变量在后端启动时读取。
3. 如果仍报超时，先查看后端是否连接 `127.0.0.1:7897`，再确认 Clash 的 `Antigravity` 策略组能访问 Cloud Code。仅看到代理接受 CONNECT 请求，还要确认上游返回 HTTP 响应。
4. 如果 Google 返回地区拒绝或账号停用提示，记录错误文字和时间。该类响应由服务端发出，本地代理设置只能解决连接问题。

下方命令测试 Clash 能否连接 Cloud Code。此处的 HTTP 404 来自无鉴权的根路径探测，表示 HTTPS 连接已建立。模型是否可用以 App 的模型列表刷新结果为准。

```sh
curl --silent --show-error --max-time 10 --noproxy '' \
  --proxy http://127.0.0.1:7897 --output /dev/null \
  --write-out 'CONNECT %{http_connect}, upstream %{http_code}\n' \
  https://daily-cloudcode-pa.googleapis.com/
```

## 回滚代理配置

交付包安装的配置可用 `python3 setup.py uninstall` 移除。如果是按原方案手动添加的，则删除 `.zshenv` 中以“仅为 Antigravity 桌面后端提供 Clash 代理”为注释的配置段，然后退出并重启 App。

## 官方图标启动后自动加载简中和看板

2026 年 11 月 22 日实测通过。日常直接点击官方 Antigravity 图标。首次打开时，后台辅助请求 App 正常退出，再打开同一个官方应用一次。窗口就绪后，辅助进程加载 Context Viewer v0.8.10 的简中词库和看板。Clash 保持运行，TUN 可以关闭。

自动启动使用用户级 LaunchAgent `local.antigravity.interface-enhancements`。它监听官方 App 的启动通知，已经带调试端口的实例会直接跳过，退出请求超时则保留当前窗口。辅助进程由 macOS 在用户登录后启动。App 更新后需要重新检查兼容性。端口由系统分配，仅监听 `127.0.0.1`。App 退出后，端口随进程关闭。

测试阶段和正式启用后各从官方 App 路径启动一次。两次均只重开一次。主界面的“新建会话”、设置页的“通用”“外观”等中文已实测。模型菜单可以展开，官方接口返回 38 个模型条目。Context Viewer 的额度面板显示数值和更新时间，Token 用量面板也可展开。App 原始 Google 签名通过校验。

汉化覆盖窗口内的界面文案，macOS 原生菜单仍使用英文。模型名称和部分级别标签保留英文。额度数据可以读取，剩余上下文在当前样本不足时无法估算。测试未发送模型消息。

### 停用自动增强

交付包部署后，使用 `python3 setup.py uninstall` 同时撤销自动增强和交付包添加的代理配置。若只想停用自动增强，可以卸载用户级后台任务，并将配置文件移到废纸篓。退出并重新打开 Antigravity 后，代理继续由 Shell 配置提供。

```sh
launchctl bootout "gui/$(id -u)/local.antigravity.interface-enhancements"
/usr/bin/trash "$HOME/Library/LaunchAgents/local.antigravity.interface-enhancements.plist"
```

交付包安装后，可查看 `~/Library/Application Support/Antigravity Desktop Enhancements/运行日志.log`，确认单次重开和模块挂载结果。项目和平台说明见 [Context Viewer](https://github.com/elviscjn-cjn/antigravity-context-viewer/tree/v0.8.10)、[Electron 启动参数](https://www.electronjs.org/docs/latest/api/command-line-switches/#--remote-debugging-portport)和[Apple 后台任务文档](https://developer.apple.com/library/archive/documentation/MacOSX/Conceptual/BPSystemStartup/Chapters/CreatingLaunchdJobs.html)。
